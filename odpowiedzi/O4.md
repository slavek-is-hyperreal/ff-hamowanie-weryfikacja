# Odpowiedź na recenzję R4 (protokół v4 → v5)

**Sprostowanie do O3.** O3 nazwało zmianę „wariantem B”, ale v4 wdrożyło odwrotność propozycji R3 (R3: przy NaN werdykt z Wilcoxona, t jako wrażliwość; v4: zawsze t, Wilcoxon jako wrażliwość). R4-01 wykazała, że weto tworzy sam test t: jeden bieg oceniony jako ok. 10% daje różnicę rzędu −87 p.p. i rozsadza SD różnic. Usunięcie reguły „t ≠ Wilcoxon” niczego nie naprawiło.

**R4-01, R4-03 – rozwiązanie (wariant B z R4, R5 ograniczona):**
- jedynym testem głównym, zawsze (bez warunkowego wyboru), jest test Wilcoxona rangowany ze znakiem (Pratt), kategorie z wartości p (inwersja = HL); estymand: pseudomediana HL (§1, §7.1, §7.4);
- bootstrap (a) na tej samej statystyce (HL), QMNIST (c) tym samym testem; t-test jako wrażliwość (b);
- nowa nadrzędna **reguła stabilności** (§7.2): test znaków na ziarnach z awarią tylko w jednym ramieniu; istotnie więcej awarii ramienia testowanego → GORSZOŚĆ-STABILNOŚĆ. Powód: symulacja pokazała, że test rangowy przy dużym N nie przekłada kilku awarii na klasę G (5/120 NaN przy Δ = 0 → R w 99%), więc niestabilność wymaga osobnego testu;
- `choose_n`: σ_d z par bez awarii, odsetek awarii q (≥ 1%) wstrzykiwany do symulacji testu głównego (§7.6);
- symulacja kontrolna `kod/sym_nan.py` z wynikami `kod/sym_nan_wynik.txt` przed R5 (scenariusze a–d, N = 30, 60, 120, test rangowy vs t).
